═══════════════════════════════════════════════
  ИНСТРУКЦИЯ ПО ЗАПУСКУ БОТА (Windows)
═══════════════════════════════════════════════

1. Установить Python 3.11+
   https://www.python.org/downloads/

2. Открыть командную строку (cmd) в этой папке
   Shift + ПКМ → "Открыть окно PowerShell здесь"

3. Установить зависимости (один раз):
   pip install -r requirements.txt

4. Запустить бота:
   python bot.py

═══════════════════════════════════════════════
  СТРУКТУРА ПАПОК
═══════════════════════════════════════════════

bot.py                          — основной файл бота
requirements.txt                — зависимости
reports_plans.db                — база данных
temp/                           — готовые документы
templates/                      — шаблоны (не используются напрямую)
Шаблон отчета.docx              — шаблон ежемесячного отчёта
Шаблон плана.docx               — шаблон плана
Шаблон квартального отчета.docx — шаблон квартального отчёта
Шаблон сводного плана.docx      — шаблон сводного плана
Шаблоны творческих отчетов/     — создайте эту папку если нужны
  МТБ/                          — папка клуба
    МТБ_даунхил.docx            — шаблон творческого отчёта

═══════════════════════════════════════════════
  КОМАНДЫ БОТА
═══════════════════════════════════════════════

/start              — главное меню
/status             — статус документов за текущий месяц
/register           — привязать клуб (для специалистов)
/notifications_on   — включить напоминания
/notifications_off  — отключить напоминания
/cancel             — отменить текущее действие
